# Book of Dungeon Story Mapper

A browser-based prototype for visually planning branching gamebook adventures.

## Features

- Draggable numbered story nodes
- Story cards automatically grow vertically to show the full entry text
- Solid arrows = player choices/routes
- Dotted arrows = information/reveals/read events
- Mark nodes that correspond to numbers printed on dungeon maps
- Double-click nodes to edit number/title/story notes
- Browser save using localStorage
- Export/import the complete graph as JSON
- No build tools or dependencies: works directly on GitHub Pages
- Undo stores up to 20 changes; use the Undo button or Ctrl/Cmd + Z

## Live path

This copy is stored in the `story-mapper` folder of the BOD3D-TEST repository so it can be served by the existing GitHub Pages site without changing the main BOD3D test app.
